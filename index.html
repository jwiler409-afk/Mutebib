❓ Guide Utilisateur

🔐 CONNEXION & ACCÈS

Sélectionnez votre rôle:

👨‍💼 ADMINISTRATEUR

Code: 000999

Permissions: ✅ Accès complet

  • ✅ Créer/Modifier/Supprimer carnets
  • ✅ Toutes les transactions
  • ✅ Paramètres système
  • ✅ Exports complets

👤 AGENT/OPÉRATEUR

Code: 568452

Permissions: ✅ Accès limité

  • ✅ Créer/Modifier carnets
  • ✅ Dépôts et Retraits
  • ❌ Pas de suppression
  • ❌ Pas d'accès paramètres
✅ Vous êtes connecté en tant qu'Agent. Vous pouvez créer des carnets et gérer les transactions.

➕ CRÉER UN CARNET

Étapes:

  1. Cliquez "Nouveau Carnet" (menu principal)
  2. Remplissez les infos:
    • 📝 Nom & Prénom *
    • 📚 Classe/Profession (optionnel)
    • 🏠 Adresse *
    • 📱 Téléphone *
    • 📧 Email (optionnel - important pour partage)
    • 💰 Dépôt initial (optionnel, max 100,000 HTG)
  3. Cliquez "Créer le Carnet"

💰 GÉRER LES TRANSACTIONS

Dépôt ou Retrait:

  1. 🔍 Recherchez ou sélectionnez un carnet
  2. Cliquez 💰 Dépôt ou 💸 Retrait
  3. Entrez le montant (minimum 100 HTG)
  4. 📅 Optionnel: Modifiez date/heure
  5. Cliquez "Valider"

💡 Conseil: Le solde se met à jour automatiquement. Consultez l'historique en bas du carnet.

✏️ MODIFIER UN CARNET

Dans les détails du carnet, cliquez le bouton ✏️ Modifier pour:

  • Changer nom/prénom
  • Mettre à jour téléphone/adresse
  • Ajouter/modifier l'email
  • Modifier la classe/profession

📊 EXPORTS & PARTAGE

Options d'export:

  • Par Carnet: Dans détails → 📊 Excel ou 📄 PDF
  • Rapport Jour: Rapports → Aujourd'hui → Excel/PDF
  • Complet: Historique → 📊 Excel (tout)

Partager un document:

  • ⬇️ Télécharger: Récupère le fichier sur l'appareil
  • 💬 WhatsApp: Ouvre WhatsApp avec le document
  • 📧 Email: Ouvre Gmail avec les transactions écrites
  • 📱 Partage: Utilise le partage natif du téléphone

📋 HISTORIQUE & RAPPORTS

  • Historique: Vue complète de tous les carnets et transactions
  • Rapport Aujourd'hui: Totaux du jour (dépôts/retraits)
  • Rapport Semaine: Vue par jour avec détails

⚙️ PARAMÈTRES (Admin uniquement)

  • Changer Code Admin: Sécurisez votre accès
  • Supprimer Carnet: Suppression définitive avec confirmation
  • Exporter Complet: Télécharge tout en Excel
  • Mode Sombre: Thème de l'application

ℹ️ IMPORTANT: Tous les données sont stockées en local sur votre appareil. Faites des sauvegardes régulières via Excel!
